# First-aid UI

React + TypeScript page with first-aid, prevention and wellbeing tips for students.
The live Q&A behind it is the AI service (`POST /api/ai/ask` on the core API). Its guidance
deliberately matches these tips.

Needs **Node.js 20.19+ or 22+** (Vite 8).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

Owner: see `.github/team.toml` (area `first-aid-ui`).
