# MediFlow Glossary

| Term | Meaning |
|---|---|
| AI assistant | The user-facing first-aid/enquiry experience |
| API | HTTP interface used by browser and services |
| Admin | User role allowed to create student accounts and perform administrative actions |
| Authentication | Verifying who a user is |
| Authorization | Verifying what an authenticated user may do |
| Backend | Server-side API, authentication, persistence, and business rules |
| CSRF | Cross-site request forgery; an attack requiring request-origin defenses |
| EMR | Electronic medical record |
| ESI | Emergency Severity Index; a triage concept in the wider architecture |
| FE | Frontend/browser application |
| FastAPI | Planned Python framework for a future AI inference service |
| First-aid tip | General emergency/first-aid educational guidance, not diagnosis |
| HTTP-only cookie | Browser cookie unavailable to JavaScript, useful for sessions |
| MediFlow | Hospital operations and patient-flow platform |
| Patient record | Identity, contact, and medical report data managed by the application |
| RBAC | Role-based access control |
| Session | Server-tracked authenticated browser state |
| Staff | General healthcare-system account role |
| Student | Account created by an administrator for future student functionality |
| Triage | Clinical prioritization performed by qualified staff |
| Widget | The bottom-right authenticated AI help box |
